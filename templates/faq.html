Preguntas frecuentes

Todo lo que necesitás saber sobre Web Analyzer & Optimizer.

¿Qué hace exactamente el plugin?

El plugin aplica correcciones automáticas en tu sitio WordPress: agrega meta tags (OG, description, canonical), lazy loading a imágenes, alt text faltante, atributos defer/async a scripts bloqueantes, shortcodes para newsletter y CTAs, y formularios de captura de email. Todo sin que edites código.

¿Qué NO es Web Analyzer?

Web Analyzer no es una solucion magica ni un truco de posicionamiento instantaneo. Es una herramienta de auditoría técnica que detecta y corrige errores invisibles en el código de tu sitio: meta tags faltantes, lazy loading de imágenes, scripts bloqueantes, formularios sin labels, Open Graph tags ausentes. Son correcciones que Google, los navegadores y los lectores de pantalla necesitan para entender y rankear tu sitio correctamente. Los cambios no son visuales — no vas a ver la página distinta. Pero Google sí la ve distinta. Los resultados en buscadores pueden tardar entre 2 y 7 días (a veces más) dependiendo de cuándo Google re-indexe tu sitio. Si buscás resultados inmediatos y visibles, esta herramienta no es para vos.

¿Cómo instalo el plugin en WordPress?

WordPress Admin → Plugins → Añadir nuevo → Subir plugin → seleccioná el archivo .zip que descargaste → Instalar ahora → Activar. Listo, las correcciones se aplican solas.

¿El plugin modifica el contenido de mis entradas o páginas?

No. El plugin trabaja a nivel técnico (meta tags, scripts, lazy loading, formularios). No edita ni borra ninguna entrada, página, imagen o configuración de WordPress. Tu contenido queda exactamente como está.

¿Qué hago si el plugin causa un error?

Todos los plugins de Web Analyzer incluyen un mecanismo de seguridad: si el plugin detecta un entorno incompatible, se desactiva solo y muestra un aviso en el admin. Si igual necesitás desactivarlo manualmente, entrá por FTP a /wp-content/plugins/ y renombrá la carpeta del plugin. También podés escribirnos a soporte.

¿Con qué versión de WordPress y PHP funciona?

WordPress 5.0 o superior y PHP 7.4 o superior. Compatible con la gran mayoría de themes del repositorio oficial y themes populares como Astra, GeneratePress, Divi, OceanWP, Hello Elementor y Kadence.

¿Puedo usar el plugin en más de un sitio?

El plugin se genera a medida para la URL que analizaste. Si querés optimizar otro sitio, analizalo por separado y descargá su plugin específico. Cada análisis genera un plugin único adaptado a ese sitio.

¿Qué pasa si ya tengo otro plugin de SEO (Yoast, RankMath, etc.)?

El plugin de Web Analyzer está diseñado para convivir con plugins de SEO populares. No reemplaza sus funciones: agrega las correcciones que esos plugins no cubren (lazy loading, formularios, CTAs). Si hay conflicto con algún meta tag, el plugin detecta si ya existe y no lo duplica.

¿Cuánto tarda en verse la mejora después de instalar el plugin?

Las correcciones técnicas (meta tags, lazy loading, scripts) son inmediatas. El impacto en buscadores depende de cuándo Google re-indexe tu sitio, lo cual suele tomar entre 2 y 7 días. Volvé a analizar tu URL en 48-72 horas para verificar la mejora.

¿Qué incluye el plan gratuito y qué el plan PRO?

Gratis: análisis completo con scorecard, hallazgos, recomendaciones y guía en markdown. PRO (ARS 12.000): todo lo anterior + descarga del plugin WordPress (.zip), archivos HTML corregidos y reporte JSON completo.

¿Cómo comparto los resultados del análisis?

Cada análisis genera un link público que aparece debajo del scorecard. Copialo y compartilo: muestra el puntaje general y por categoría, sin necesidad de que la otra persona tenga cuenta.
