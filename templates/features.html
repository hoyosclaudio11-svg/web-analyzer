Todo lo que hace

Diagnóstico automático + solución instalable en un solo flujo.

⚡

Rendimiento

Detecta scripts bloqueantes, imágenes sin lazy loading, formatos no optimizados y exceso de requests. El plugin agrega loading="lazy", defer/async y corrige el orden de carga.

♿

Accesibilidad

Encuentra imágenes sin alt text, contraste bajo, formularios sin labels, estructura de headings rota y links sin texto descriptivo. Correcciones automáticas vía plugin.

🔍

SEO

Audita meta title, meta description, OG tags, canonical, headings (h1-h6), y longitud de títulos. El plugin agrega o corrige los meta tags faltantes automáticamente.

🎯

UX

Evalúa tiempo de carga, diseño responsive, legibilidad, contraste y jerarquía visual. Recomendaciones específicas para mejorar la experiencia del visitante.

💰

Conversión

Detecta formularios sin captura de email, CTAs débiles o ausentes, falta de newsletter y oportunidades de conversión perdidas. El plugin agrega shortcodes [newsletter] y [cta].

📦

Plugin WordPress

Descargá un .zip listo para instalar. Subilo a WordPress, activalo, y todas las correcciones técnicas se aplican solas. Sin editar código ni tocar templates.

📊

Scorecard 0-10

Puntaje en 5 categorías con código de colores (verde/amarillo/rojo). Promedio general y detalles por categoría. Compartí el resultado con un link público.

🔄

Re-análisis

Después de instalar el plugin, volvé a analizar la URL para verificar la mejora. El historial guarda todos tus análisis anteriores con fecha y puntaje.
